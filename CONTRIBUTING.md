# Contributing

Thanks for improving OpsPilot.

1. Open an issue for behavior changes or new integrations.
2. Create a focused branch from `main`.
3. Add or update tests with the implementation.
4. Run `./mvnw verify` and validate changed n8n workflow JSON.
5. Open a pull request describing behavior, risk, and verification.

Do not commit API keys, production alerts, personal data, or employer-owned code. Keep model-driven actions advisory unless the change includes explicit human approval and an auditable allowlist.
